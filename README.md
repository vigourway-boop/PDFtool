## 📖 软件简介

**PDFtool**（作者：vigourway）是一款专为 Windows 打造的**纯离线、单文件绿色版**全能 PDF 桌面工具箱。无需安装配置、不依赖网络，双击一个 `PDFtool.exe` 即可运行，所有文档全程本地处理，充分保护隐私与数据安全。

软件采用清爽现代的原创工作室界面（支持深浅双色主题与智能文件拖拽分流），一站式集成 **33 项高频实用功能**——涵盖流畅阅读批注、无损保留电子签章的文档合并与发票拼版、高保真 PDF 转 Word（支持复杂公式、带标插图与框线表格精准还原）、**纯离线 Anki 制卡工作台（图像遮挡/F键智能识表识字/截图问答/高亮抽卡/真题批量切卡直出 `.apkg`）**、离线 OCR 文字识别、交互式白边裁剪、电子签字盖章、页面整理、体积压缩、加密脱敏及批量处理等，轻松搞定日常学习、科研与办公中的各类 PDF 难题。

## ⚡ 核心亮点

1. **纯离线单文件绿色版 (`PDFtool.exe`)**：
   - 不启动任何本地 Web 服务或浏览器内核，零网络端口占用。
   - 所有引擎（高保真排版模块、离线神经网络 OCR 模型、签章保护引擎）完全封装于单个 exe 中，即拷即用。

2. **原创桌面工作室界面架构**：
   - **左侧常驻分类导航**：工作台总览、我的收藏夹与四大功能分区随心切换。
   - **顶部智能拖拽分流**：将文件直接拖入首页顶部横幅，单份 PDF 自动打开阅读、多份 PDF 自动合并、图片自动合成 PDF、Word/Excel 自动格式互转。
   - **Windows 资源管理器右键菜单集成**：支持免管理员权限一键注入右键快捷阅读与合并入口，支持随时一键卸载。

3. **电子签章与防伪标记无损保护**：
   - 针对高校审批表、电子合同、发票与公文深度定制，提供深拷贝无损保护模式与矢量固化模式，合并打印不丢失印章二维码，彻底杜绝“签名无效 ❌”红叉警告。

4. **自研 Native Exact-Order 纯离线 PDF 转 Word 双引擎**：
   - 彻底修复开源转换工具常见的 `/SMask` 黑色实心方块、幽灵大图重叠、伪流式表格炸裂与复杂公式撕裂问题。
   - 针对理综试卷、物理力学/电学图、坐标网格与分式根号实现 360 DPI 高保真还原，精准对齐原页码。
   - 针对框线表单（如结题验收表）自动保持原生可编辑 Word 单元格与手写签名。

5. **🆕 纯离线 Anki PDF 专业制卡工作台（v1.1.0 重磅新增）**：
   - **图像遮挡卡**：支持矩形/椭圆画框、`Shift` 多框编组、`F` 键三层离线智能扫框（自动识别表格单元格 / 文本行 / 扫描件内置 OCR）、`P` 键透视与跨页贴框；采用**共享 WebP 底图 + 纯矢量 SVG 遮罩**（内置防泄题闪烁与 iOS 防偏移修复），**PC / 安卓 / iOS 全端免插件直接复习**。
   - **截图问答 + 高亮抽卡 + 真题切卡**：蓝绿框跨页截图配对（公式/配图 100% 不乱码）、一键扫描 PDF 高亮转 `{{c1::...}}` 挖空卡、按题号自动切题并支持挂载独立答案 PDF 配对，支持双面仿真预览、直出标准 `.apkg` 及 AnkiConnect 本地一键直传。

## 🧰 33 项功能全清单（四大工作流分区）

### 🔥 第一组：常用高频核心（首屏置顶）
1. **阅读浏览**：无广告清爽内置阅读器，目录大纲树、缩略图导航、平滑缩放与全文检索高亮。
2. **文档合并**：三种签章保护策略（无损保留 / 矢量固化 / 原件包）、多文件拖拽排序与自动书签。
3. **文档拆分**：固定页数、自定义页码区间、单页全拆、奇偶页或一级章节拆分。
4. **内容批注**：打字输入、白底覆盖原位改字、荧光笔高亮、自由画笔、图形绘制与印章插图。
5. **签字盖章**：平滑手写签名板、自动生成公章/方章、多页骑缝章与 PKCS#12 数字签名。
6. **格式互转**：PDF 与 Word（3种策略：智能高保真/经典流式/1:1原貌）、Excel、Markdown、HTML、TXT 本地互转。
7. **体积瘦身**：标准、强力、无损与自定义压缩模式，矢量字体清晰锐利。
8. **发票拼版**：发票/讲义 2合1 / 4合1 / 6合1 / 9合1 带虚线 A4 拼版，公章二维码完整保留。

### 📑 第二组：页面整理与图像互转
9. **删除页面**：点选缩略图或输入区间快速剔除多余空白页与无用页。
10. **提取页面**：按勾选页合并导出为新文档，或每页独立存为单页。
11. **页面旋转**：单页点选旋转或按横向/纵向一键智能批量纠正。
12. **页面排序**：拖拽缩略图自由混排，支持全篇倒序与双面扫描错位校正。
13. **插入与替换**：无损替换指定页区间，或在任意位置插入外部页与空白页。
14. **白边裁剪**：智能图文边界自动切边、鼠标拉框交互式裁剪与数值边距裁剪。
15. **图片合成**：JPG / PNG / WebP / BMP / TIFF 多图合成，支持原图自适应与标准 A4。
16. **导出图片**：逐页导出 96~450 DPI 高清图或一键拼接单张超清纵向长图。

### 🖋️ 第三组：识别改字与版面编排
17. **Anki 制卡** `学习神器`：纯离线三栏制卡工作台，支持图像遮挡（`F` 键自动识表/识字/OCR、`Shift` 多框编组）、蓝绿框截图问答、PDF 原生高亮自动抽卡与真题按题号批量切卡，直出免插件 `.apkg` 牌组包（全端兼容 PC/安卓/iOS）及 AnkiConnect 直传。
18. **文字识别**：内置离线神经网络 OCR 引擎，扫描件转可复制检索的双层 PDF 或纯文本。
18. **替换文字与背景**：自动匹配字体颜色原位查找改字，或设置豆沙绿/羊皮纸护眼底色。
19. **目录与属性**：多级章节书签可视化编辑（支持智能抓取大字标题生成目录）与元数据修改。
20. **编排页码**：6 方位页码、对开书籍外侧页码、自定义起始编号与跳过封面。
21. **添加水印**：斜向多行平铺防盗文字水印或透明 Logo 图片水印，支持置顶/置底。
22. **页眉页脚与贝茨号**：动态变量页眉页脚与卷宗级连续递增贝茨流水号。
23. **提取内嵌图**：无损提取正文与签章内嵌原始位图，自动合成透明通道输出 PNG。
24. **批量处理**：多文档队列批量压缩、加水印、编页码、贝茨号、切白边、加密或转长图。

### 🛡️ 第四组：安全脱敏与进阶工具
25. **加密保护**：AES-256 高强度加密，配置独立打开密码及防打印、防复制权限。
26. **密码解锁**：验证密码导出永久无密副本，或对普通权限限制一键瞬间解锁。
27. **敏感涂黑**：底层字节流物理级不可逆擦除，支持划框涂黑与身份证/手机号关键词全文脱敏。
28. **文档比对**：逐页像素级与文本级双重比对，生成左右并排差异审阅报告。
29. **底纹叠加**：红头公文模板、单位信笺或安全底纹精准套印到页面。
30. **新建文档**：Markdown 排版直接生成 PDF，或一键生成横线纸、方格纸、点阵纸、康奈尔笔记本。
31. **网页转存**：本地 HTML 文件、HTML 源码或离线网页转为矢量文档。
32. **结构优化**：启用 Fast Web View 线性化、精简垃圾对象、清除隐私元数据。
